Teamwide AI

Your saved Reels, ready to ask.

Connect Instagram once. Then tell Claude to pull your newest saved reel. It saves every word, a picture from every second and the caption, and you can ask it anything.

This uses two free tools made by other people, not us: Reels Vault and instagram-mcp. We ran the steps below ourselves on Nov 2, 2026.

On your phone? Send this page to your computer. Setup happens there.

What you get from each reel

One note, saved on your computer. We tested a 57 second reel and got all of this in under 30 seconds.

  • Every wordThe full transcript, with times.
  • A picture from every secondUp to 60, so Claude can see what was on screen.
  • The detailsCreator, caption, hashtags, likes and comments.
  • The songWhen Shazam can name it.
  • A topic folderHooks, sales, health, whatever you pick.

What you need

Claude CodeOr Codex. On your computer. It does the install for you.
2.5 GB freeFor both tools and the browser they use.
15 minutesOnly for setup, one time.

Set it up

We tested this on a Mac. The tool also lists Windows steps, but we did not test those.

Step 1

Find a reel to test

On Instagram, open any public reel. Tap share, then Copy link. Send the link to your computer.

Step 2

Paste this into Claude Code

Install Reels Vault from https://github.com/Overusedhydra/reels-vault using the Claude Code steps in its README. Install anything that is missing, including Python 3.10 or newer, ffmpeg and ffprobe. Link its skill into my Claude skills folder. Keep my notes in a folder called My Reels in my Documents folder, and create that folder first. Then save this reel as a test: PASTE YOUR REEL LINK HERE

Swap the last part for your reel link. Then hit enter.

Claude will ask to run a few commands. Say yes. The install took us under 3 minutes. The first save takes a bit longer, because it downloads the speech model one time.

Step 3

Connect your Instagram

Read this first. This step uses an unofficial tool. Instagram's rules ban automated access, so your account could get flagged. Use it only on your own account, pull a few reels at a time, and stop if Instagram shows a warning. You can skip this step and paste links instead. 
Install instagram-mcp from https://github.com/YoppaV/instagram-mcp using its README and add it to Claude Code. My Instagram username is YOUR USERNAME. Run the login step so a browser window opens and I can log in myself. Never ask for my password in this chat.

A browser window opens. Log in there, not in the chat. Then close and reopen Claude Code.

The tool only reads. It has no way to like, follow, comment or DM. It only talks to Instagram, and your login stays on your computer in a file that works like a password. The login lasts a few weeks. When it ends, ask Claude to run the login step again.

Step 4

Pull your saves

No links needed. Just ask.

Pull my most recent saved reel and save it to Reels Vault.

Want a few? Keep it small. We stay at 10 or less, and we don't run it twice in a row.

Pull my last 5 saved reels and save them to Reels Vault. Skip any already saved.

Skipped step 3? Copy a reel link on Instagram and use this.

Save this reel: PASTE LINK
Step 5

Ask your saves

This is the good part. Claude answers from your own notes.

What did I save about hooks? Give me the top 3 ideas and the links.

To use the pictures too, ask this.

Look at the frames from that reel. What did they show on screen in the first 3 seconds?

Good to know

  • It pulls when you ask. It does not run in the background. New saves come in when you tell Claude to pull them.
  • Reels only. Photos and carousels will not turn into notes. Reels from private accounts will not download.
  • Saving a reel needs no login. Only pulling your Saved list uses your Instagram login. Public reels saved with no login in our tests.
  • Works with Claude Code and Codex. Using Codex? Paste the same messages and say Codex instead of Claude Code. We tested saving and asking in Codex, but not the install or pulling your Saved list. The regular ChatGPT app can not do this.
  • Your notes stay with you. Words are written down on your own computer. It goes online to reach Instagram and to ask Shazam about the song.

If something breaks

Paste the error into Claude Code first. It can usually fix it. These are the ones to expect.

What you seeWhat to do
Python 3.10+ requiredNormal on most Macs. We hit this too. Tell Claude: install Python 3.12, then try again.
ffmpeg or ffprobe not foundTell Claude: install ffmpeg and ffprobe, then try again.
Folder doesn't existTell Claude: create the My Reels folder in Documents, then try again.
Executable doesn't existThe browser is missing. We hit this too. Tell Claude: run playwright install chromium for instagram-mcp.
Session expired or not logged inTell Claude: run the instagram-mcp login step again, and log in yourself in the window.
The download failsInstagram sometimes blocks downloads. Log in to Instagram in Chrome, then tell Claude: try again with cookies from Chrome.
Claude cannot find the tool in a new chatTell Claude: link the Reels Vault skill into my Claude skills folder.
